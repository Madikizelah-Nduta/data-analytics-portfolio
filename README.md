# Data Analytics Portfolio
**Madikizelah (Maddie) Nduta** | Data Analyst | Power BI, SQL, Python, Excel | Kenya (UTC+3), open to remote roles

Twelve business analytics projects, each with a formula-driven Excel workbook, a dashboard and a write-up explaining the method. Built under **BZME Insights**.

> **Note:** all data is synthetic and created for demonstration. Targets, rates and thresholds are illustrative.

## Skills
- **BI and visualisation:** Power BI (DAX, Power Query), Tableau, Excel dashboards
- **Data and programming:** SQL, MySQL, Python (Pandas), Excel (VBA, PivotTables, Power Query)
- **Analytics:** KPI design, RFM and ABC analysis, SLA and risk reporting, variance analysis, FP&A forecasting, M&E indicators, survey quality checks, scenario analysis, data cleaning

## How to explore a project
1. Open a project folder and read its README (business question, results and screenshot).
2. Download the Excel workbook and open the Dashboard sheet.
3. Change a value on the Assumptions sheet to see everything recalculate.
